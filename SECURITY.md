# Security Policy

This repository builds and publishes a static blog to GitHub Pages. Pushes to
`main` deploy the site.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
<https://github.com/chinmaymjog/chinmaymjog.github.io/security/advisories/new>

This includes problems in the site's workflow, theme overrides or any content
that exposes private information.

You can expect an initial response within a few days.

## Supported versions

Only the latest `main` (the live site) receives fixes.
